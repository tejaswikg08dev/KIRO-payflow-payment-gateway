# PayFlow Merchant Dashboard

React frontend for merchant portal — transactions, settlements, API keys, analytics.

## Setup (Follow Phase 11 docs)

```bash
npm install
npm run dev
# Opens: http://localhost:3000
```

## Tech Stack
- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS (styling)
- TanStack Query (API state)
- React Router v6 (navigation)
- Recharts (charts)
- React Hook Form (forms)
