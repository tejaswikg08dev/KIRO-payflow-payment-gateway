# PayFlow Hosted Checkout

Customer-facing payment page — card form, UPI, net banking, 3D Secure OTP.

## Setup (Follow Phase 11 docs)

```bash
npm install
npm run dev
# Opens: http://localhost:3001
```

## Features
- Card payment form (Luhn validation)
- UPI payment (enter VPA)
- Net Banking (bank selection)
- 3D Secure OTP verification
- Success/Failure result pages
- Mobile responsive
- Merchant branding support
